# מקום לשבעה

אתר Next.js בעברית להשכרת סוכות אבלים, מוכן לפריסה ב-Vercel.

## לפני פרסום
1. בקובץ `app/page.tsx` החליפו את `0500000000` במספר ה-WhatsApp העסקי (מספר ישראלי).
2. עדכנו את שם העסק, אזורי השירות, סוגי הסוכות והתנאים לפי השירות בפועל.
3. אפשר להוסיף תמונות אמיתיות של הסוכות ופרטי קשר.

## הפעלה
```bash
npm install
npm run dev
```

## פרסום ב-Vercel
העלו את התיקייה לריפוזיטורי GitHub, ואז ב-Vercel בחרו Add New → Project, חברו את הריפוזיטורי ולחצו Deploy. זיהוי Next.js אוטומטי.

הטופס אינו כולל שרת או אחסון נתונים. לחיצה על שליחה פותחת הודעת WhatsApp מוכנה, למספר שהוגדר בקוד. לפני הגדרת מספר אמיתי, הפניות לא יגיעו לעסק.
