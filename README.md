# סוכות נחמה

אתר Next.js לשירות השכרת סוכות אבלים בפריסה ארצית.

## העלאה ל-GitHub ול-Vercel

העלו **את תוכן התיקייה** לשורש המאגר, תוך שמירה על תיקיית `app`. חברו את המאגר ל-Vercel עם Framework Preset של Next.js ו-Root Directory `./`.

## לפני פרסום

1. החליפו את `0500000000` בקובץ `app/page.tsx` במספר WhatsApp האמיתי.
2. החליפו את תמונות ההמחשה בתמונות אמיתיות של הסוכות. התמונות הנוכחיות הן תמונות אווירה ואינן מייצגות בהכרח את הציוד.
3. אמתו שהיקף השירות, הציוד והזמינות תואמים לפעילות העסק.

הטופס פותח WhatsApp עם הודעה מוכנה, ולא שומר פניות בשרת.
